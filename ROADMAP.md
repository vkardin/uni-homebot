# Дорожная карта

Цель: UNI — домашний сервер в Telegram, который любой может развернуть у себя (свой экземпляр, свой бот-токен).

## Сделано
* **5.x** — отвязка от одного сервера: мастер первого запуска, установка одной командой и Docker, нейтральные
  значения по умолчанию, интеграции только если включены, плитки, подключение из чата, каталог приложений.
* **6.0** — доска приложений, модули, самовосстановление, ремонт сервера по PIN, центр уведомлений, новый облик панели.

## 6.x — доделать 6.0
* 6.1 «Начало работы» в чате (/setup) и на главной панели; подключение приложений подсказывает /connect.
* 6.2 Настройки из панели: часовой пояс, валюта, погода, пороги алертов, бэкап. `.env` главнее.
* 6.3 Настоящие модули: не только плитки, но и новости, напоминания, инструменты, ИИ, погода, игры.
* 6.4 Доска приложений 2.0: статус «онлайн/офлайн», группы и порядок.
* 6.5 Перенос: экспорт и импорт настроек, бэкап перед обновлением.
* 6.6 Стабилизация.

## 7.x — открытый проект
* 7.0 Языки (ru/en/uk), лицензия, проверка кода на каждый коммит, документация для новичков.
* 7.1 Подписанные обновления из GitHub Releases, каналы «стабильный/тестовый», откат.
* 7.2 Debian, Fedora, Arch, Raspberry Pi; готовый Docker-образ.
* 7.3 Каталог модулей и шаблонов приложений от сообщества.
* 7.4 Публичный сайт; юридическая проверка yt-dlp и неофициального Binance P2P API.

## 8.x — семья и несколько серверов
Роли и права на модули, хранилище людей в SQLite, агент UNI для других машин, сводная доска, бэкапы между серверами.

## 9.x — автоматизация
Сценарии «если, то», Home Assistant и MQTT, локальный помощник на Ollama, отчёты за неделю, месяц и год.

## 10.0 — платформа
Стабильный API модулей, полный паритет чата и панели, обновление с любой 6.x одной командой с откатом.
