# Дорожная карта

Цель: UNI — домашний сервер в Telegram, который любой может развернуть у себя (свой экземпляр, свой бот-токен).

## Сделано
* **5.x** — отвязка от одного сервера: мастер первого запуска, установка одной командой и Docker, нейтральные
  значения по умолчанию, интеграции только если включены, плитки, подключение из чата, каталог приложений.
* **6.0** — доска приложений, модули, самовосстановление, ремонт сервера по PIN, центр уведомлений, новый облик панели.
* **6.1–6.6** — «Начало работы», настройки из панели (`.env` главнее), разделы-модули, доска приложений 2.0,
  перенос настроек и бэкап перед обновлением, стабилизация.
* **7.0–7.4** — языки (ru/en/uk), лицензия и CI, подписанные обновления из GitHub Releases, Docker-образ и
  несколько дистрибутивов, каталог сообщества, сайт и правовые заметки.
* **8.0–8.1** — роли (Семья, Друг, Гость), агент UNI для других машин с копиями бэкапов.
* **9.0–9.3** — сценарии «если, то», Home Assistant, вопросы о сервере к локальной модели, отчёты за неделю,
  месяц и год.
* **10.0** — платформа: внешние модули (API 1.0, docs/MODULES.md), паритет чата и панели под автотестом,
  обновление с любой 6.x без миграций, критерии готовности (docs/READY.md).

## Дальше (10.x)
* MQTT напрямую, без Home Assistant.
* Модули из каталога сообщества одной кнопкой (сейчас — папкой в `STATE_DIR/modules`).
* Сводная доска нескольких серверов с ремонтом по PIN на любом из них.
* Полный перевод интерфейса на en и uk.
