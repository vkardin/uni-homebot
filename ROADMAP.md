# Дорожная карта

Цель: из личного бота сделать проект, который можно развернуть на своём сервере (модель «у каждого свой экземпляр и свой бот-токен»).

## 5.x — отвязать от одного сервера
* Мастер первого запуска в чате (BOT_TOKEN/ADMIN_ID без ручного `.env`), установка в одну команду, Docker Compose.
* Убрать личные настройки по умолчанию: валюта, часовой пояс, украинские подборки новостей, Actual/Radarr/Sonarr/Binance — только если включено.
* Поддержка не только Ubuntu/apt.

## 6.0 — модули
* Каждая функция (новости, P2P, слежка, финансы, кино, конвертер…) — модуль с манифестом, включением и настройкой из панели.
* Реестр модулей, проверка зависимостей (`detect()` как у конвертера), единый экран «Модули» в панели и в `/doctor`.

## 7.0 — публичный проект
* Языки (ru/en/uk), подписанные релизы вместо любого `.tar.gz`, GitHub Actions (ruff + тесты), лицензия, документация для чужих.
* Юридически проверить: yt-dlp и неофициальный Binance P2P API.

## Идеи на потом
Личные слежка за сайтами/игры/P2P у гостей, личные финансы, квоты ИИ и перевода для гостей, OCR и перевод документов, редизайн сообщений чата.
