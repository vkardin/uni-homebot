# Правовые заметки

UNI — программа, которую каждый ставит на свой сервер и использует сам. Автор не предоставляет никаких
услуг и не получает ваших данных. Это не юридическая консультация: если сомневаетесь, проверьте законы своей
страны и условия сервисов, к которым подключаете бота.

## Скачивание видео (yt-dlp)

* В «Инструментах» есть скачивание по ссылке через [yt-dlp](https://github.com/yt-dlp/yt-dlp) (лицензия Unlicense).
* Многие сайты запрещают скачивание в своих правилах, а чужие материалы защищены авторским правом.
  Скачивайте только то, на что у вас есть права (своё, свободно распространяемое, разрешённое правообладателем).
* Гостям скачивание доступно только с отдельным правом, которое выдаёт владелец.
* Раздел целиком выключается: Модули → 🧰 Инструменты.

## Курс Binance P2P

* Модуль 💱 P2P читает публичные объявления Binance P2P через неофициальный адрес, который использует их сайт.
  Официального API для этого нет, адрес может измениться или перестать работать в любой момент.
* Бот только читает цены, ничего не покупает и не продаёт, не входит в аккаунт и не хранит ключей Binance.
* Условия Binance могут ограничивать автоматический доступ к сайту. С версии 5.1 модуль выключен по умолчанию
  на новых установках (`P2P_ENABLED=false`) и по умолчанию запрашивает данные раз в 5 минут.

## Остальное

* Новости берутся из RSS-лент, которые вы выбираете; бот показывает заголовки и ссылки на источник.
* Переводы и пересказы делает локальная модель на вашем сервере (Ollama) или ваш LibreTranslate.
* Код распространяется по лицензии MIT (`LICENSE`) без каких-либо гарантий.
