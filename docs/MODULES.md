# Внешние модули UNI (API 1.0)

Модуль добавляет боту свои команды и фоновые задачи, не трогая код UNI. Пример: [`extras/modules/uptime`](../extras/modules/uptime).

## Установка

1. Скопируйте папку модуля в `STATE_DIR/modules/` (обычно `/var/lib/homebot/modules/`, в Docker — `data/modules/`).
   Имя папки = `id` модуля.
2. Панель → Ещё → Модули: видны название, команды и **права**. Включите переключателем.
3. Нажмите «Перезапустить бота». Команды модуля появятся в меню «/», статус — в `/modules`.

Выключенный модуль даже не импортируется.

## module.json

```json
{
  "id": "uptime",
  "name": "Аптайм сайтов",
  "version": "1.0.0",
  "api": 1,
  "description": "Проверяет, открываются ли сайты",
  "permissions": ["network", "files", "notify"],
  "commands": [{"command": "uptime", "description": "Сайты"}]
}
```

`id` и команды — латиница в нижнем регистре, цифры и `_`. Команда, которая уже есть у UNI или другого модуля,
не загрузится. `api` должен совпадать с версией API в UNI (сейчас `1`).

## module.py

```python
def setup(uni):
    async def hello(args: str) -> str:
        return "Привет, " + (args or "мир")  # ответ в чат, можно HTML

    async def every_hour() -> str | None:
        return None  # текст — придёт владельцу; None — молчать

    uni.command("hello", hello)
    uni.every(3600, every_hour)  # нужно право "notify", не чаще раза в минуту
```

| Что | Право | Описание |
|---|---|---|
| `uni.command(name, fn)` | — | команда из `commands` в module.json |
| `uni.every(seconds, fn)` | `notify` | фоновая задача; видна и выключается в «Фоновых задачах» |
| `uni.http` | `network` | `aiohttp.ClientSession` бота |
| `uni.docker` | `docker` | Docker API UNI (`containers_raw()`, перезапуск) или `None` |
| `uni.data_dir` | `files` | своя папка `modules/<id>/data` |
| `uni.log` | — | журнал `homebot.module.<id>` |

## Что гарантирует UNI

* API 1.0 не меняется в 10.x. Несовместимые изменения — только с новым номером `api`, старые модули тогда
  честно не загрузятся с понятной ошибкой.
* Ошибка импорта или `setup` — модуль помечается ошибкой в панели и `/modules`, бот работает дальше.
* Команда упала — «модуль ошибся»; три ошибки подряд — модуль отключается до перезапуска. Таймаут команды 60 с.
* Права — ограничение по интерфейсу, а не песочница: код модуля выполняется внутри бота. Ставьте только то,
  чему доверяете, и читайте `module.py` перед включением.

Модули не входят в бэкап UNI: храните их исходники отдельно (например, в git).
