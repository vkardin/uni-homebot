# Общий стиль приложений

Используется vkardin UI 1.0.0: нейтральные светлая и тёмная палитры, карточки 16 px, поля 10 px, основные кнопки в форме капсулы, видимый фокус и уважение к уменьшению анимации.

Источник общих CSS-токенов и JS-помощников — `vkardin/video-glow`, каталог `ui-kit/`. Копии включаются в каждый пакет локально, без сетевой загрузки. Запуск `python ui-kit/sync.py --workspace /path/to/checkouts` обновляет соседние репозитории, `--check` проверяет совпадение копий.

В общую часть входят только представление и простые обработчики элементов управления. Обработка звука, PiP, захват экрана и серверные API остаются отдельными. Существующие дополнительные темы Video Glow сохранены. Нативный Snapt использует ту же палитру и выбранный знак «Фокус».

Следующие полезные объединения: одинаковое отображение ошибок сохранения, формат импорта и экспорта настроек с версией схемы, общая проверка доступности элементов и длинных переводов. Перенос поведения требует отдельных регрессионных тестов каждого продукта.
