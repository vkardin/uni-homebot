# 🛡 Сторож UNI в облаке

Маленький сервис на Cloudflare Workers, который продолжает работать, когда дома нет света или интернета.
Домашний бот раз в минуту сообщает ему «я жив». Если сигналов нет 3 минуты, Сторож пишет через своего бота:

* `🔌 Дом не на связи с 14:02` — сразу, как сигналы пропали;
* `⚡ Дом снова на связи. Не было 2 ч 14 мин` — когда сервер вернулся, с догадкой: сервер перезагрузился
  (значит, пропадал свет) или работал всё время (пропадал интернет);
* `/status` — на связи ли дом и последние цифры (CPU, память, диск, температура, аптайм);
* `/history` — отключения за 30 дней и сколько всего не было связи.

Стоимость — 0: хватает бесплатного тарифа Cloudflare (100 тыс. запросов в сутки, Сторожу нужно около 1,5 тыс.).

## Что уходит в облако

Только сводка: имя машины, версия UNI, CPU, память, самый заполненный диск, температура, аптайм, нагрузка и часовой
пояс. Токены, пароли, адреса приложений, финансы, файлы и сообщения остаются дома. Сторож не может ничего
сделать с сервером: он только принимает сигналы и отвечает владельцу.

## Почему отдельный бот

Telegram отдаёт сообщения бота только одному получателю. Если дом и облако будут слушать один токен, они начнут
мешать друг другу. Поэтому у Сторожа свой бот, а основной бот работает дома как раньше.

## Установка одной командой

Нужны Node.js 20+ и бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/sign-up) (карта не нужна).

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`), откройте его и нажмите «Старт».
2. На сервере (или любом компьютере с этой папкой) запустите:

   ```bash
   bash extras/watchdog/setup.sh
   ```

   Скрипт спросит токен бота-сторожа и ваш Telegram id (подставит `ADMIN_ID` из `/opt/homebot/.env`), откроет вход
   в Cloudflare, развернёт Сторожа, сам придумает секрет, подключит вебхук и предложит дописать `WATCHDOG_URL` и
   `WATCHDOG_TOKEN` в `.env`. Без прав на запись в `.env` он просто покажет строки.
3. Перезапустите бота: `sudo systemctl restart homebot` (в Docker: `docker compose restart`).

Через минуту `/status` у бота-сторожа покажет 🟢.

## Установка вручную (то же самое по шагам)

1. Создайте бота у [@BotFather](https://t.me/BotFather), например `my_home_watch_bot`, и скопируйте токен.
   Откройте нового бота и нажмите «Старт», иначе он не сможет вам написать.
2. Придумайте общий секрет для дома и облака (от 16 символов):

   ```bash
   openssl rand -hex 24
   ```

3. Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com/sign-up) (карта не нужна) и разверните Сторожа:

   ```bash
   cd extras/watchdog
   npx wrangler login
   npx wrangler deploy                      # покажет адрес вида https://uni-watchdog.<имя>.workers.dev
   npx wrangler secret put BOT_TOKEN        # токен бота-сторожа из шага 1
   npx wrangler secret put CHAT_ID          # ваш Telegram id (тот же, что ADMIN_ID у основного бота)
   npx wrangler secret put HEARTBEAT_TOKEN  # секрет из шага 2
   ```

4. Подключите бота-сторожа к Telegram (один раз):

   ```bash
   curl -X POST https://uni-watchdog.<имя>.workers.dev/setup -H "Authorization: Bearer <секрет>"
   ```

   Бот-сторож пришлёт «🛡 Сторож UNI подключён».

5. В `.env` основного бота добавьте и перезапустите его:

   ```ini
   WATCHDOG_URL=https://uni-watchdog.<имя>.workers.dev
   WATCHDOG_TOKEN=<секрет>
   ```

   Через минуту `/status` у бота-сторожа покажет 🟢. В основном боте появится фоновая задача «Облачный сторож»:
   её можно выключить, например на время переезда.

## Настройки

В `wrangler.toml`, после правки снова `npx wrangler deploy`:

* `TIMEOUT_MIN` — сколько минут тишины считать отключением (по умолчанию 3);
* `TZ` — часовой пояс в сообщениях. Если не задан, берётся часовой пояс домашнего бота.

В `.env` бота: `WATCHDOG_INTERVAL_SEC` — как часто слать сигнал (по умолчанию 60 секунд). Таймаут Сторожа должен
быть хотя бы в 2–3 раза больше интервала.

## Ограничения

* Точно отличить «нет света» от «нет интернета» без второго устройства нельзя. Подсказка по аптайму обычно верна,
  но если сервер и роутер стоят на ИБП, отключение света Сторож заметит, только когда сядет батарея.
* Перезапуск бота или обновление короче таймаута сообщений не вызывает.
* Удалить Сторожа: `npx wrangler delete` в этой папке и убрать `WATCHDOG_URL` из `.env`.

Проверка логики: `node --test extras/watchdog/*.test.mjs`.
